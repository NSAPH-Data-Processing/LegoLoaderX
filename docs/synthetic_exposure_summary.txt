--------------------------------------------------------------------------------
1. WHAT AND WHY
--------------------------------------------------------------------------------
We need to score an exposure-response-curve (ERC) estimator, which requires a
dose-response we already know. On real data no such answer key exists.

So we write the outcome ourselves: the daily hospitalisation count of each ZCTA
is drawn from a Poisson rate that WE specify, with a known dose-response beta.

Previously only the OUTCOME was synthetic; the exposures were the real PM2.5 /
gridmet fields. That left the confounder -> treatment arm uncontrolled: we knew
how much the exposure moves the outcome, but not how much the confounders move
the exposure. Now BOTH arms are ours: the 5 environmental exposures are also
generated, as an explicit treatment-assignment model with a known, strong
dependence on the (real) confounders.

Result: a naive exposure-outcome fit is provably biased (+100-150%, measured),
and only a correctly adjusted estimator recovers beta. That is the test.

--------------------------------------------------------------------------------
2. THE TWO EQUATIONS
--------------------------------------------------------------------------------
(A) TREATMENT ASSIGNMENT - how each exposure e is generated (src/synthetic_exposure.py)

    T_e[t,i] = mean_e + sd_e * x_e[t,i]

    x_e = sqrt(f_dr) * z(sum_k w_ek * C~_k)     <- confounder signal   f_dr = 0.60
        + sqrt(f_st) * z(SAR_rho AR1_phi noise) <- space/time structure f_st = 0.20
        + sqrt(f_no) * z(iid noise)             <- independent noise    f_no = 0.20

    z(.) = standardize to mean 0, sd 1.  C~_k = standardized confounder k.
    The three parts are independent, so OLS(T_e ~ all confounders) has
    R^2 = f_dr = 0.60 BY CONSTRUCTION (measured 0.59-0.60, table 5).
    f_no > 0 is deliberate: it guarantees overlap/positivity, i.e. the exposure
    still varies at fixed confounder values, so do(T = a) is not extrapolation.

(B) OUTCOME - how the count is generated (src/synthetic_causal.py, unchanged form)

    lambda[t,i] = max( 0.01,  base + seasonal(t) + geo(lat,lon)
                             + beta * PM25[t,i]
                             + sum_k gamma_k * C~_k[t,i] )

    Y[t,i] ~ Poisson( lambda[t,i] * o_i ),   o_i = 0.0003 * population_i

    beta = 0.01 is the ground truth. PM2.5 enters RAW (so beta is per ug/m^3);
    everything else enters STANDARDIZED (so gamma is per standard deviation).

 READ THIS ROW-WISE. A variable is a confounder OF THE PM2.5 EFFECT only if it
 has BOTH a "-> Y" entry and a "PM25" entry. That is 8 of the 12:
   income, poverty, home value, education, over-65, black, hispanic, renters.
 The other 4 are deliberately NOT confounders of PM2.5:
   - pop_non_us_citizen: affects the outcome only (a pure precision variable,
     zero weight in all five exposures);
   - pop_under_20, pct_cfa, pct_dfa: affect the outcome and the OTHER exposures,
     but not PM2.5 directly.
 The 4 generated gridmet exposures are themselves confounders of the PM2.5 arm:
 they affect Y (gamma) and share drivers with PM2.5 (over-65, poverty, income,
 home value), so they co-vary with it. The correct adjustment set is therefore
 all 16 terms (4 gridmet + 12 census/climate).

 exposure shape / confounder shape linear (sqrt / log1p / U-shape available, unused)
 interactions                      OFF
 outcome-rate spacetime coupling   OFF  (spacetime.rho = 0, phi = 0)   <-- NOTE
 spatial graph                     kNN, k = 8, on ZCTA centroids
 grid                              32,657 mainland ZCTAs x 365/366 days
 years                             2011-2020 (10 years x 5 exposures = 50 files)
 diseases                          27
 seeds                             exposures 12345, outcome 42 (byte-reproducible)

 NOTE on the last coupling: the SAR + AR(1) operator is applied to the
 EXPOSURES (rho, phi in table 3, always on). Applying it to the OUTCOME rate is
 implemented and unit-tested but currently switched off. Turning it on is a
 one-line config change and does not break the closed-form ERC (the operators
 are mean-preserving, so the exposure slope stays exactly beta).

--------------------------------------------------------------------------------
6. THE GROUND-TRUTH ERC
--------------------------------------------------------------------------------
 Estimand (g-computation), matching what the model reports:

   F(a) = mean over nodes z of [ sum over forecast days t of E[Y_zt | do(PM2.5 = a)] ]

 do(PM2.5 = a) forces the exposure to a in every cell; confounders keep their
 observed values. Ignoring the 0.01 clamp this is exactly LINEAR:

   F(a) = A + B*a,     B = beta * |T_forecast| * mean(o)

 So the slope recovers beta up to a known scale factor. Three notes:
  - on the RATE scale (divide by the offset, no time sum) the slope is exactly beta;
  - on the default COUNT scale (whole year summed, averaged over nodes) the curve
    sits in the hundreds - same information, different units;
  - src/ground_truth_erc.py does NOT use the linear formula. It evaluates the true
    clamped rate at each a and averages, so it is exact; A + B*a is only the shape
    that explains why the slope is beta.

 The ERC is invariant to how the exposures were generated: do(.) overrides the
 exposure term entirely. Making the treatments synthetic changed what is on disk,
 never the estimand.

 Answer key travels with the data: every counts parquet gets a .manifest.json
 snapshot of the DGP parameters + git commit, and ground_truth_erc.py reads that
 manifest, not the live config - so editing the config later cannot silently
 invalidate the ground truth.

8. HOW IT IS RUN (three stages, in this order)
--------------------------------------------------------------------------------
 Stage 0  exposures   sbatch jobs/generate_exposures.sbatch
                      src/synthetic_exposure.py
                      -> data/covars/synth_exposure/<var>/<var>__<year>.npy

 Stage 1  outcomes    sbatch jobs/regenerate_outcomes.sbatch
                      src/synthetic_health.py  (Poisson draw)
                      -> .../medicare_synthetic/.../sparse_counts_<var>_<year>.parquet
                         + <...>.manifest.json

 Stage 2  format      sbatch jobs/format_health.sbatch
                      snakefile_health.smk -> dense .npy store the dataloader reads
                      -> data/health/ccw/<var>/<var>__<year>.npy

 Ground-truth ERC     python -m src.ground_truth_erc year=2011 synthetic.var_name=diabetes

 ORDER MATTERS. The outcome reads the exposures off disk, so regenerating
 exposures after outcomes silently invalidates the ground truth. Regenerate both.

 All outputs go to a personal overlay
 (/n/dominici_lab/lab/projects/julian/lego/), symlinked as data/covars and
 data/health. The shared lab store is untouched.

--------------------------------------------------------------------------------
9. LIMITATIONS, STATED UP FRONT
--------------------------------------------------------------------------------
 - The rate is additive-linear in every term. Non-linear shapes (sqrt, log1p,
   U-shape) and interactions are implemented but switched off, so the ERC is a
   straight line - the easiest possible target. Harder shapes are one config edit.
 - The 0.01 rate floor binds for 2.2% of cells; the ground truth accounts for it
   exactly, but it makes the closed-form A + B*a slightly approximate.
 - PM2.5 is clipped at 0, pinning 1.4% of cells; the exposure is therefore not
   exactly Gaussian at the low end.
 - Confounding strength is currently uniform (R^2 = 0.6 for all five exposures).
   A weak/strong sweep would be more informative than a single operating point.
 - Only the confounders in the table exist. There is no unmeasured confounding
   by construction, so this validates estimator mechanics, not robustness to
   violated assumptions.
